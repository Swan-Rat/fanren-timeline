# 凡人修仙传 · 灵界篇 时间线与地图可视化

基于《凡人修仙传》（忘语 著）网络流传 2446 章全本**逐章核对**整理的灵界篇（第 1261–2446 章）可视化项目。纯静态、零依赖，克隆后双击 HTML 即可离线使用；也可直接开启 GitHub Pages（根目录即站点）。

## 页面

| 文件 | 内容 |
|---|---|
| **灵界篇-纪传体时间线.html** | 纵向纪传体时间线：韩立本纪（所在地/修为条带＋大事卡）＋按需懒加载的人物泳道（核心列传 8 人、灵宠别传 4 只、扩展人物库 71 人按阵营分组可搜索）；分段渲染长卷、交汇事件联动高亮、跳转/密度/主题切换；**事件标记/卡片/表格行点击弹出「原文精炼」弹窗**（76 景约 160 条原文引文） |
| **灵界地图-选点展示.html** | 以同人地图《灵界地图总览》为底的选点地图（可切原文方位示意图）：30 地点节点 × 79 人物足迹投射，点节点看该地人物、搜人物反向高亮足迹、韩立行程叠加（22 段序号）、地点×人物总表；人物事件点击弹「原文精炼」 |

> 两页需与 `灵界地图总览.png` 保持同目录。

## 数据文件

| 文件 | 内容 |
|---|---|
| **人物数据库.json** | 71 位扩展人物：阵营/身份/出现章节段/地点（region 对应灵界地理），由全文文本挖掘生成、重点人物人工校订 |
| **原文精炼数据库.json** | 76 个场景的原文精炼引文（每景 1~3 条、≤90 字，OCR 已校，出处章号经核） |

两页 HTML 均已内嵌同一份数据；JSON 供二次利用（更新数据后需同步内嵌）。

## 口径与勘误

- 章节编号采用本项目核对底本；底本在约 1669/1965 与 2119–2201 两区间存在章号错位（内容顺序正常），涉及处页面已注明。
- 网友年历表多处讹误已按原文勘正（如"厉飞雨"化名实始于雷鸣云城、六翼霜蚣叛变无"神风舟"情节、"银月蛇双修之约"无文本依据、冰凤重逢实在第 1819 章、紫灵重逢实在第 2120 章、"泣血秘藏"应为泣灵秘藏等）。
- 原文极少写明韩立年龄，各"≈参考年龄"为网友推算，仅作量级参考。
- 地理表述以原文为准（如人族居风元大陆**西北角**，底图绘于东北）；地图节点为近似落位。
